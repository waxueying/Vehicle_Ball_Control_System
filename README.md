# 车载平衡滚球运动控制系统

双 MCU 分布式架构的车载滚球系统：TI MSPM0G3507 主控驱动小车沿黑线巡线行驶，STM32 调节摆杆控制钢球位置；MaixCAM2 视觉模块运行 YOLO 实时识别钢球坐标，实现小车行驶过程中的钢球厘米级动态平衡。

全国大学生电子设计竞赛 2026 年 H 题

## 系统架构

```mermaid
flowchart LR
    subgraph V["视觉板 MaixCAM2"]
        CAM["YOLO 实时检测钢球坐标<br/>解算偏移 (cm) 与球速 (cm/s)"]
    end

    subgraph S["滚球控制板 STM32F103"]
        RX["UART2<br/>12 字节定长帧解析"]
        POS["位置环 PID<br/>偏移 → 目标球速"]
        VEL["速度环 PID + 球速阻尼前馈<br/>球速 → 舵机 PWM"]
        IMU["ICM20602<br/>车体加速度前馈"]
        RX --> POS --> VEL
        IMU --> VEL
    end

    subgraph M["底盘控制板 MSPM0G3507"]
        SEN["8 路灰度 / 双编码器"]
        LOOP["线位置环 PID + 轮速环 PI"]
        MOT["双电机差速"]
        SEN --> LOOP --> MOT
    end

    CAM -- "偏移 / 球速" --> RX
    VEL --> SRV["舵机"]
    SRV --> BEAM["摆杆倾角"]
    BEAM --> BALL(("钢球"))
    BALL -. "视觉观测" .-> CAM
    MOT --> CAR["车体沿黑线行驶"]
    CAR --> BEAM
    CAR -. "加减速惯性扰动" .-> BALL
```

两块控制板各自独立闭环，没有板间通信：底盘不读取钢球状态，滚球板也不控制车速；小车加减速对钢球造成的惯性扰动，由滚球板上的 IMU 就地测量并前馈补偿。

## 硬件

| 部分 | 器件 | 说明 |
| --- | --- | --- |
| 底盘控制 | MSPM0G3507 | TI DriverLib，CMake + arm-none-eabi-gcc |
| 滚球控制 | STM32F103C8T6 | HAL 库，Keil MDK 工程 |
| 视觉 | MaixCAM2 | 运行 YOLO 实时识别钢球坐标，串口下发偏移与球速（识别程序不在本仓库） |
| 被控对象 | 钢球 | 沿摆杆滚动，目标为保持在摆杆设定的目标位置 |
| 姿态传感 | ICM20602 | 六轴 IMU（软件 I2C），测量车体加速度用于前馈 |
| 执行器 | 舵机（50 Hz PWM）+ 双直流电机 | 舵机驱动摆杆倾角，电机差速驱动底盘 |
| 反馈 | 8 路红外灰度、双路编码器 | 线位置、轮速与里程 |
| 交互 | OLED、板载按键、蓝牙串口 | 状态显示、模式切换、无线调参 |

## 关键技术点

### 滚球平衡控制（ball_balancer）

- 串级 PID：位置环（位置式，输出/积分限幅）输出目标球速，速度环（增量式 + 一阶低通）输出舵机 CCR，33 ms 控制周期；位置死区内冻结输出，误差过零时重置积分与速度环
- 双前馈补偿：视觉球速阻尼前馈；ICM20602 车体加速度前馈（一阶低通 α=0.03、零偏校正、30 cm/s² 死区）
- 与视觉板的自定义串口协议：12 字节定长帧（0xAA55 帧头 / 0x0D0A 帧尾 + 两个 float），逐字节中断状态机非阻塞解析，配合数据新鲜度标志避免重复积分
- 手写软件 I2C（PB6/PB7）驱动 ICM20602，含零偏标定与单位换算
- 按键与视觉板双向握手：按键消抖后下发模式，视觉板回 ACK 后本板生效

### 底盘循迹控制（car_base）

- 20 ms 定时中断内完成双闭环：8 路灰度归一化加权求线位置 → 转向 PID；编码器测速 → 增量式速度 PI
- 双环输出差速驱动左右轮，速度设定值斜坡平滑起停
- 里程由轮速积分得到，实现多档速度下的定点停车
- 蓝牙串口环形缓冲 + `[a,b,c]` 文本帧解析，用于无线调参与数据回传

## 实测数据

| 指标 | 数值 |
| --- | --- |
| 钢球稳态位置误差 | ≤ 1 cm |
| 小车加减速时钢球最大偏移（前馈前 / 前馈后） | 3 cm 以上 → 1 cm 以内 |
| 巡线最高档速度 / 是否脱线 | 最高档速度下稳定巡线，未脱线 |

## 分工与个人工作

1. 设计滚球平衡控制：以钢球位置为被控对象设计串级 PID（位置环输出目标球速、速度环输出舵机倾角），叠加视觉球速阻尼前馈与 IMU 车体加速度惯性前馈，实现钢球的厘米级控制
2. 自定义串口帧协议：将 MaixCAM2 识别的球位置与球速送入 STM32 控制回路，中断状态机非阻塞解析，丢帧可自恢复
3. 编写巡线小车代码：以 8 路灰度归一化加权求出的黑线位置为外环、编码器实测轮速为内环构成串级 PID，双环差速输出驱动左右轮，配合速度斜坡与里程积分实现多速度档巡线与定点停车
